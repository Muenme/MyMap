Комфорт-карта — Android-приложение, которое помогает найти туалет, лавочку, урну или фонтанчик с водой в конкретной ситуации: «хочу в туалет прямо сейчас», «иду с коляской до парка», «нужна лавка в тени». В основе — Clean Architecture + MVVM на Kotlin, карта на MapLibre, офлайн-кэш на Room и текстовый ИИ-ассистент, который превращает свободный запрос в параметры поиска.
